# My portfolio

Personal Portfolio built with **Python** and **Streamlit**


## Tools

**Streamlit** is an open-source Python framework for data scientists and AI/ML engineers to deliver dynamic data apps with only a few lines of code.  
Documentation : https://docs.streamlit.io/

**Python** is a programming language that lets you work more quickly and integrate your systems more effectively.  
Documentation : https://www.python.org/doc/versions/  
I used Python 3.10

## Deployment

Deployed on Streamlit Community Cloud after pushing to github : https://streamlit.io/cloud  

To access my portfolio, click here : https://gracia-gokar-portfolio.streamlit.app/
